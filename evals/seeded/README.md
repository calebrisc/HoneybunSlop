# Seeded-bug evals (milestone 4)

Each case will be a small task on a sample game with a known-correct solution and planted defects (missed criterion, assertion-free test, special-cased test input, frame-rate dependence, a SCRIPT ERROR that exits 0, a claim with no evidence). Metrics per layer: catch rate, false-positive rate on correct solutions, unique catches, tokens and time. A layer with no unique catches over two runs is cut.
